Don't drop out of the match when Steam goes away steamkeep-2 test

When Steam loses its connection during a match (a failure, Steam updating its servers, Steam restarting), the game leaves the match and often closes. With this the whole match is played to the end, however long Steam is away and however often it drops - the game itself runs through the game server, Steam is not needed for it. Steam's request to close the game is not followed until the match is over; your own Alt+F4, Quit in the menu and the close button work. After the match the game stays open, the result and the replay go out as usual. A match over Steam P2P without a relay can't be saved.

Gameplay

Jumps don't break on obstacles jumpretry-2 test

For the Autarch and other jumpers: if, on the way to the jump point, he hopped over an obstacle by himself and that broke the jump order, the order is repeated right after the landing (up to 3 times). The repeat is the game's own order - nothing changes for the other players; any new order you give the squad cancels it.

Fix: Elite.exe crash on Windows 11 25H2 elitefix-nowmic-1 test

After starting the game Elite.exe checks its launch parameters with the old Windows tool wmic, which Windows 11 25H2 no longer has - so Elite.exe crashes (Windows log: Elite.exe, 0xc0000409). The game itself keeps running. This tick puts an Elite.exe without that check (one instruction changed into a jump to its normal ending); everything else is as it was. Untick to get the original Elite.exe back.

Other

Record game crashes (for the developers) crashlog-1 test

If the game closes by itself (the window vanishes, Windows records nothing), tick this, repeat the crash and press "Send logs" in the launcher. Elite_DLLs gets CrashLog.log - where in the code the error happened and what closed the game (the game's built-in BugSplat crash reporter closes it silently) - and a small dump CrashLog_*.dmp. Changes nothing in the game, sends nothing anywhere.

For vanilla DoW2 (no launcher)

Unpack into the game folder next to DOW2.exe: you get winmm.dll and the dow2-patches folder. winmm.dll is a small loader: it loads every .dll from dow2-patches, so the packages can be combined — if you already have it, copy only the new .dll into dow2-patches. Game files are not changed; to remove, delete winmm.dll and the folder.

Preview build, not checked on our stand yet. It updates itself to the final version later. Windows installer.
