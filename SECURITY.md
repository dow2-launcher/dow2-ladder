# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately through GitHub: open the **Security** tab of this repository and press
**Report a vulnerability**. You can also write to pivolan@gmail.com.

Please include what is affected, how to reproduce it and what an attacker could do with it.
We will answer within a few days and credit you in the changelog if you want.

## Supported versions

Only the latest version on `main` (and the latest release shipped through the Elite launcher) gets fixes.
